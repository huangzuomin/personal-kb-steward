# demo 基线公开合成素材评分标准（rubric）

本文档定义 T0 阶段用于卡片提炼质量评估的公开合成素材与评分标准。所有素材均为 **SYNTHETIC 合成内容**（人物、机构、数字均为虚构），不用于验证私有 demo 数据，也不构成事实主张。基线质量已获用户接受，无需重新审批。

## 质量分层原则

- **机器检查**（pytest）：文件存在、manifest 一致、SYNTHETIC 标记在位、负例保持"故意损坏/空/无关/重复"、hash 快照可重算。机器检查只能证明素材与结构合规。
- **人工语义评审**：按下列五类 rubric 逐项回答"可观察的验收问题"，结论为 pass / revise / fail。**仅凭 schema 合规不得判语义合格。**
- 空结果、无冲突、无关联可以是正确答案——前提是给出明确理由。禁止捏造数量配额（例如"必须产出 N 条卡片"）。

## 五类 rubric（最低要求，均为必选）

### 1. source（来源笔记）—— 对应 fixture：`research_summary_uncited_01`

最低要素：原始出处与来源性质说明 + 概括摘要 + 关键陈述 + 主题提示词 + 素材特有质量标注。
验收问题：提炼出的 source note 是否明确标出"无引用/示意性数字/不可核实"？是否保留了主题（共享单车调度）而不虚构出处？

### 2. seed（种子卡片）—— 对应 fixture：`dialogue_user_ai_01`

最低要素：一个想法 + 归属（谁说的：用户本人 vs AI 提案）+ 具体成长点/反例/边界 + 诚实的关联或"暂不关联"。
验收问题：用户自我归因（如"收藏与写作目标错配"）是否与 AI 提案（如"反向过滤"）被区分归属？是否保留了提案三的选题漂移边界？

### 3. concept（概念页）—— 对应 fixture：`project_case_01`（"三段转化链"）或 `neg_repeated_quote`（"潮汐淤积"）

最低要素：定义 + 解释 + 近似概念的边界（如转化链 vs 一般促销；潮汐淤积 vs 一般供需失衡）+ 若有理由可给别名。
验收问题：机制是否被定义为可独立复用的抽象，而非绑定在书店细节上？边界是否说明"何时不适用"？

### 4. case（案例卡片）—— 对应 fixture：`project_case_01`

最低要素：背景 + 行动 + 结果（未核实数字须显式标注）+ 机制 + 适用性 + 证据等级。
验收问题：4%→11%、22% 等数字是否仍带"店主自报台账、无对照"标注？三段转化链是否与故事叙述分离？

### 4b. 多源主题组 topic_groups —— 对应 fixture 组：`case_family_conversion_chain`（project_case_01 / _followup / _counterexample）

研究问题（显式）：三段转化链在什么条件下有效、在什么条件下失效？
验收问题：
- 是否区分了**口径差异**（当晚 vs 30 天测量窗口、打开者 vs 报名者分母）与**事实冲突**？口径不同导致的数字差异不得记为矛盾。
- 是否保留了**可识别的解释分歧**：店主（当场口径直接体现机制）vs 财务顾问（当晚口径夸大效应），且不裁决、不升格任一方？
- 是否把反例（拾光读书会）正确记为**条件差异下的失败应用**（免费替代品、信任语境、渠道弱），而非"机制普遍失效"的事实冲突？
- 缺口（无对照记录、线下课程场景未覆盖）是否显式列出？下一步是否有排序？
- 无关素材（如 `neg_irrelevant`）不得被强行纳入该主题；无关联可为正确答案，但须说明理由。

### 5. topic（主题卡）—— 完整基线使用上述三源案例组；单源报告只验收 stub

最低要素：主题与来源映射 + 已支持的分歧/语境差异 + 缺口 + 排序后的下一步。
验收问题：是否列出了"哪些说法有素材支撑、哪些只是示意性"？缺口（如缺实测数据）是否被显式记录？下一步是否有优先级排序而非并列清单？

`research_summary_uncited_01`（共享单车调度）仅用于单源受限主题草稿测试，必须明确标记为 stub/证据不足，不能凭这一个来源通过完整主题基线。完整主题使用 `case_family_conversion_chain` 三源组；三个路径也不自动代表三个独立证据来源，应保留共同案例背景和自报限制。

## 负例预期

| fixture | 预期正确行为 |
|---|---|
| `neg_empty` | 不产出任何卡片，理由：空文件 |
| `neg_irrelevant` | 判为无关/不入库，理由：无主题、无论点 |
| `neg_damaged` | 标记损坏来源，不强行解读 |
| `neg_repeated_quote` | 独立单元数 ≤1，不按篇幅折算价值 |
