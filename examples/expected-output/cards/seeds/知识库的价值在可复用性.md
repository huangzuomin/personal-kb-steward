# 知识库的价值在可复用性

## 核心议题

知识库不是资料越多越好，而是能不能形成可复用的**证据、案例和工作记忆**。

（这条念头实际上就是这个工具自身的设计命题——它既是内容，也是一条验收标准。）

## 来源文件

- [[quicknote/005-random-thought.md]]

## 关键信号

- 原文只有这一句，没有展开。三类资产（证据 / 案例 / 工作记忆）的划分是念头自带的，未论证。

## 可生长方向

- **「可复用」的判据是什么？** 被引用次数？被复述次数？被用作写作素材？需要一个可观察的代理指标，否则这句话无法证伪。
- **为什么是这三类？** 证据、案例、工作记忆的分工是什么？三者之间是什么关系（并列？递进？）？
- **反例方向。** 如果库里 90% 的内容从未被引用，这条念头是成立（正因为没形成可复用资产）还是被证伪（资料本身就是价值）？
- **与本工具的直接对撞。** 这条念头要求的正是「证据、案例、工作记忆」三类资产；而当前流水线**只稳定产出 sources 与 seeds 两类**，`cases/`、`concepts/`、`materials/` 长期为空。→ **这条念头可以用来检验工具自身的完成度。**
